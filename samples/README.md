# Образцы

Здесь лежат файлы, на которых гоняются проверки: счета площадок для сборки
Pro Forma и готовые спецификации для накладной CMR.

В открытом репозитории их нет — это настоящие документы покупателей: машины,
суммы, имена. Проверки, которым нужны образцы, при их отсутствии пропускаются,
а не падают. Положите сюда свои файлы, и они заработают:

- `facture_sample.pdf`, `facture_bmw.pdf` — счета Ayvens
- `sag_sample.pdf` — счёт SAG
- `openlane_sample.pdf`, `openlane_ru.pdf` — счета OPENLANE
- `spec_golfstream.xlsx` — готовая спецификация
- `spec_dogruz_1.xlsx`, `spec_dogruz_2.xlsx` — две спецификации одной машины
