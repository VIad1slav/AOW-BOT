# AOW Document Converter

Telegram-бот, который делает торговые документы AOW GROUP из того, что приходит
от площадок и поставщиков.

Две цепочки:

- **платёжка с аукциона (PDF) → Faktura Pro Forma (DOCX)** — счета Ayvens/TEMSYS,
  SAG и OPENLANE распознаются автоматически, данные покупателя берутся из
  фотографии паспорта по MRZ;
- **Pro Forma (DOCX) + спецификации (XLSX) → комплект документов**: Faktura
  (DOCX), спецификации (XLSX и PDF) и накладная **CMR** (PDF).

## Из чего состоит

| Файл | Что делает |
|---|---|
| `bot.py` | диалог в Telegram, приём файлов, сборка комплекта |
| `proforma.py` | разбор счетов площадок и сборка Pro Forma по шаблону |
| `passport.py`, `ocr_worker.py` | чтение MRZ паспорта отдельным процессом |
| `translit.py` | адрес из кириллицы в польскую латиницу |
| `buyers.py` | справочник покупателей |
| `processing.py` | правка DOCX и XLSX: вёрстка, ширина столбцов, перевод упаковки |
| `cmr.py` | накладная CMR из готовых спецификаций |
| `docx_text.py` | замены в DOCX по прогонам, которые Word рвёт на части |
